# Practice: Build Advanced Pivot Tables

## Task Brief
Create multi-level pivot tables with filters and calculated fields; document logic in notebook.

## Scenario
Extend your capstone repo with advanced pivot table examples summarizing transaction data by region, product, and time.

## Deliverables
- Excel file with 3+ advanced pivot tables
- Jupyter notebook documenting pivot logic

## Success Criteria
- Pivot tables use multiple row/column fields
- At least one calculated field present
